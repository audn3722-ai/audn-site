# Сайт Азиатского университета дружбы народов (АУДН)

Статический сайт на Astro. Публикуется автоматически на GitHub Pages при каждом изменении.

## Как добавить новость
1. Откройте https://app.pagescms.org и войдите через GitHub.
2. Выберите репозиторий `audn-site` → «Новости» → «Add an entry».
3. Заполните заголовок, дату, язык, фото и текст → «Save».
Через 1–2 минуты новость появится на сайте.

## Где менять телефон, email и тексты
Файл `src/i18n.ts`: блок `info` (телефон, email) и тексты страниц.

## Подключение домена www.audn.kg (когда будет зарегистрирован)
1. В `astro.config.mjs`: `site: 'https://www.audn.kg'`, `base: '/'`.
2. Добавить файл `public/CNAME` с текстом `www.audn.kg`.
3. DNS у регистратора: CNAME `www` → `audn3722-ai.github.io`;
   A-записи для `audn.kg` → 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153.
4. GitHub → Settings → Pages → Custom domain: `www.audn.kg`, включить «Enforce HTTPS».
